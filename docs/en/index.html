Rust research prototype · v0.2 · 2026

A post-quantum digital currency, designed for privacy

On a conventional blockchain, every payment is public and recorded forever. Obscura publishes the opposite: nothing. Not the amounts, not the senders, not the recipients — and its security is built to survive a quantum computer.

▲

Educational prototype, with no security audit. The code is complete and tested end to end, but nothing has been reviewed by a cryptanalyst. Do not entrust it with anything of value. There is no public chain: no faucet and no explorer, by decision.

In brief

Four things to know before digging in

◈

Complete privacy

On chain there are only commitments and nullifiers. Amounts, senders and recipients are never published.

◱

Defence in depth

Every security function rests on two primitives from independent families. The whole holds if at least one holds.

◎

The STARK is the consensus

The circuit statement does not accompany the rule: it is the rule. There is no second definition to drift away from.

◔

Finality, not mining

A committee of authorities produces blocks, with a quorum certificate checked before any proof. An absent authority is routed around.

The detail behind each of these, and above all the five known limitations of the prototype, are on the project page — shown in the body of the page, not relegated to a footnote.

Try it

What you can run today

There is no binary to download: no release has been published. You fetch the source and build it — Rust 1.87 is enough.

three commands
git clone https://github.com/nailiwalid-del/obscura.git
cd obscura
cargo run --release --bin obscura-demo

That last command starts two real nodes and passes a transaction between them. To set up a chain of your own — your genesis, your sealing node, a wallet that pays — the full walkthrough is on the Get started page, where every command was verified by real execution, all the way to a received payment.

Invitation-only network

The only path you can follow alone is the local testnet. Joining a federation requires an invitation and an out-of-band key exchange: there is no public bootnode, no directory, and no “join” button.
